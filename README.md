# Machine-Learning-SO2-Emissions
Here is the code used in the final workflows for the project: Applying ML Techniques to Constrain Sulphur Dioxide Emissions (summer 2026 UROP).

Note that some of the .py files are designed to be converted to .ipynb files (via jupytext).

All directories and data used within this workflow is stored on the sheat_mip gws on Jasmin under my username (ajs224), and the code is designed to work with those directories available. The code can be adapted to be used by changing those directories and other user parameters, all which are labelled.

Not all figures or metrics used in the evaluation script have been used in the results or have been looked deeply in to, so apologies if anything is unclear/not the highest of quality!

Wayyyy more demo files and outdated methods are also included on the sheat_mip gws (although the scripts are not all fully annotated and some may not be entirely functional - I chose to stick with the ones used for the final project to make pretty and upload here !!).
